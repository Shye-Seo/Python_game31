# 🕹️ 숭구리 레트로 웹 미니게임 아케이드 (Retro Web Mini-Games)

서승혜 님의 웹 기반 레트로 미니게임 모음집 프로젝트입니다.  
브라우저에서 설치 없이 바로 즐길 수 있는 4가지 클래식 캐주얼 게임을 제공합니다.

---

## 🎮 수록 게임 목록

1. **🍦 배스킨라빈스 31 (Baskin Robbins 31)**
   - 1~3개의 숫자를 번갈아 부르며 마지막 **31을 부르는 사람**이 패배하는 심리전 게임!
   - 4n+2 필승 전략 알고리즘이 탑재된 똑똑한 AI와 1:1 대전.
2. **⚾ 3자리 숫자 야구 (Bulls & Cows)**
   - 0~9까지 중복 없는 3자리 비밀 숫자를 맞추는 추리 두뇌 게임.
   - 스트라이크(S), 볼(B), 아웃(OUT) 실시간 판정 및 히스토리 로그 기록.
3. **⚡ 초고속 반응속도 테스트 (Reaction Speed Test)**
   - 빨간색(대기) ➔ 초록색(클릭)으로 바뀌는 순간 밀리초(ms) 단위로 반응속도 측정.
   - 프로게이머(상위 5%), 신의 반응속도(상위 1%) 등 티어 판정 시스템.
4. **🎴 카드 짝맞추기 (Memory Card Game)**
   - 4x4 그리드에서 귀여운 푸드 이모지 8쌍을 가장 적은 턴 수로 뒤집어 맞추는 기억력 게임.

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3 (Modern Glassmorphism & Cyber Retro UI), Vanilla JavaScript (ES6+)
- **Hosting**: GitHub Pages 호환 (정적 웹 배포)
- **Design**: 반응형 웹 디자인 (모바일 & 데스크톱 완벽 대응)
